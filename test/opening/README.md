# 첫 연결 / TRUSS LAB opening

겨울 계곡의 교량을 배경으로 한 35초 일러스트 오프닝입니다. 사용자가 선택한 방향은 시네마틱 교량, 움직이는 일러스트, 30~40초입니다. 이 폴더에는 해당 방향으로 제작한 첫 버전이 들어 있습니다.

## 감상

BridgeV8을 HTTP 서버로 제공한 상태에서 다음 경로로 진입합니다.

- `opening/scene.html`: 감상 후 기존 `index.html` 타이틀로 자동 이동
- `opening/scene.html?preview=1`: 감상 후 끝 화면에서 정지. 다시 보기와 게임 진입 가능

예를 들어 프로젝트 루트에서 다음처럼 실행합니다.

```powershell
python -m http.server 8878 --bind 127.0.0.1 --directory BridgeV8
```

미리보기: <http://127.0.0.1:8878/opening/scene.html?preview=1>

기존 `index.html`은 수정하지 않았습니다. 오프닝을 포함한 배포의 시작 주소는 `opening/scene.html`로 지정합니다. `index.html`을 직접 방문하면 기존 게임부터 시작하며, 컷신으로 되돌아오는 리다이렉트는 없습니다.

## 장면 구성

| 시간 | 장면 | 화면과 움직임 |
| --- | --- | --- |
| 00–09초 | THE VALLEY | 계곡과 교량 전경. 천천히 구도가 넓어지며 눈과 안개가 별도로 움직임 |
| 09–17초 | A SINGLE CONNECTION | 목재와 금속 접합부 근접 화면. 재질과 연결부를 따라 느린 카메라 이동 |
| 17–26초 | THE FIRST CROSSING | 교량 위 파란 차량을 바라보며 천천히 전진하는 시점 |
| 26–35초 | TRUSS LAB | 전경으로 복귀, 타이틀 등장, 어둡게 전환한 뒤 게임 진입 |

자막은 `서로 닿지 않던 두 곳에,` → `작은 연결이 모이고,` → `하나의 길이 됩니다.` 순서입니다.

현재 차량은 일러스트 안에 그려져 있으며, 차량만 독립적으로 주행하는 애니메이션은 아닙니다. 화면의 깊이는 카메라 이동과 별도의 눈·안개 레이어로 만듭니다. 실제 구조물 조립이나 변형을 계산하지 않습니다.

## 조작과 재생

- 시작 버튼: 이미지를 모두 읽은 뒤 활성화. 클릭으로 음향 재생 권한 확보
- 일시정지/재생 버튼, 재생 위치 슬라이더, 음소거 버튼
- `Esc`: 게임으로 이동
- 버튼·링크·슬라이더 외 영역에서 `Space`: 재생/일시정지, `M`: 소리 전환
- 다른 탭으로 이동하면 자동 일시정지. 돌아온 뒤 재생 버튼으로 계속 감상
- OS의 동작 줄이기 설정: 카메라 이동·눈·안개 생략, 짧은 장면 전환 유지
- 이미지 로딩 실패: 오류 안내와 다시 불러오기 표시, 게임 직접 진입 가능

재생 위치 하나를 기준으로 컷, 자막, 타이틀과 효과를 동기화합니다. 반복 재생에서도 별도 타이머나 이벤트를 추가하지 않습니다. `requestAnimationFrame`은 재생 중에만 동작합니다.

## 자산과 음향

- `assets/valley.png`: 계곡과 교량 전체
- `assets/joint.png`: 연결부 근접
- `assets/crossing.png`: 교량 입구와 차량

세 이미지는 내장 imagegen 도구로 생성했습니다. 첫 전경을 두 후속 장면의 시각 참조로 사용했습니다. 프롬프트는 `ART-DIRECTION.md`에 기록했습니다. 이미지 합계는 약 7.7 MiB이며 외부 이미지 주소에 의존하지 않습니다.

음향은 Web Audio로 합성한 낮은 바람과 지속 화음입니다. 녹음한 효과음이나 완성된 음악 트랙은 포함하지 않습니다. 외부 음원·폰트·라이브러리를 불러오지 않습니다.

## 수정 위치

- `scene.js`의 `shots`: 컷 시작/종료, 카메라 확대와 이동
- `scene.js`의 `captions`: 자막 내용과 시점
- `scene.css`: 화면 비율, 자막, 타이틀, 조작 UI
- `scene.html`: 시작 문구, 타이틀과 기본 접근성 구조

## 검증

`review/verify.cjs`는 로컬 Chromium의 디버깅 연결로 브라우저를 실행하는 검증 스크립트입니다. 게임에 포함되는 실행 의존성은 아닙니다.

```powershell
$env:CHROME_PATH = '컴퓨터에 설치된 Chromium 또는 Chrome 실행 파일의 절대 경로'
$env:OPENING_URL = 'http://127.0.0.1:8878'
node BridgeV8/opening/review/verify.cjs
```

확인 항목: 이미지 로딩, 재생·일시정지·다시 보기, 정지 중 시간 유지, 장면과 자막 동기화, 위치 이동, 소리 버튼, 작은 화면 가로 넘침, 동작 줄이기, 이미지 로딩 실패 후 재시도, 실제 시간으로 35초 전체 재생, 종료 시 게임 진입, ESC 건너뛰기, 실행 중 예외. 확인용 화면 캡처도 `review`에 저장합니다.

첫 버전에서 위 검사를 Chromium으로 실행해 통과했습니다. 1600×900 데스크톱과 390×844 모바일 시작 화면, 연결부·차량·타이틀 화면 캡처를 직접 확인했습니다.

자동 검사는 청각적 음질이나 실기기의 장시간 프레임 속도를 보증하지 않습니다. 최종 연출은 실제 화면과 스피커·헤드폰으로 감상하며 조정합니다.
