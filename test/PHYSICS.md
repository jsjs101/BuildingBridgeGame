# 도로 하중과 파단 판정

## 변경한 계산

- Canvas 좌표의 아래쪽이 중력 방향입니다. 정적 차량 하중·자중도 이 방향으로 적용합니다.
- 렌더링에 사용하는 차량 중심 좌표에서 차축 위치를 구합니다. 교량 밖 차축은 도로에 하중을 주지 않으며, 여러 차축과 두 차량의 하중 분담도 정적·동적 계산에서 같은 방식으로 구합니다.
- 부재의 길이와 재료별 선중량으로 자중을 구해 양 끝 관절에 나누어 적용합니다. 끊어진 부재는 정적 강성과 자중에서 제외됩니다.
- 기존 도로의 관절 변위·기울기 변화와 휨 강성으로 관절 모멘트를 복원합니다. 각 도로 패널 안의 차축 집중하중과 등분포 자중에 의한 모멘트·전단력도 계산합니다. 관절 사이에 차축이 있어도 하중이 빠지지 않습니다.
- 패널 끝, 차축 위치 양쪽, 전단력이 0인 내부 단면에서 최대 요구량을 검사합니다. 일반 도로와 강화 도로는 서로 다른 휨·전단 허용량을 갖습니다.
- 도로의 최종 이용률은 `max(축력 이용률 + 휨 이용률, 전단 이용률)`입니다. 기존과 동일하게 1.02를 초과하면 해당 부재를 끊고 남은 구조를 재해석합니다. 강성을 잃으면 기존 동적 붕괴·낙하·파단 조각 모델로 넘어갑니다.
- 삼각형 개수나 ‘트러스 유무’를 성공 조건으로 강제하지 않습니다. 짧은 경간이나 실제 중간 지지점이 있는 구조는 보강 트러스 없이도 버틸 수 있습니다. 반대로 도로를 짧은 조각으로 쪼갠 것만으로 전체 경간의 휨 하중을 피할 수 없습니다.
- 목재·강철·케이블은 차량 통로 옆의 측면 구조재로 취급해 차체 충돌에서 제외합니다. 해당 재료의 파단 조각도 동일합니다. 일반·강화 도로와 그 파단 조각은 차량 충돌 대상으로 유지하며, 구조재의 하중 계산·파단 및 다른 물체와의 충돌 처리는 그대로 유지합니다.

## 표시와 설정

동적 주행에서 도로 기울기는 왼쪽에서 오른쪽으로 주행하는 방향을 기준으로 계산합니다. 관절을 오른쪽부터 연결해도 같은 경사의 도로로 인식합니다. 기존에는 연결 순서가 반대인 도로를 약 180도 뒤집힌 경사로 읽어 접지를 잃고 도로에 충돌하는 문제가 있었습니다. 수직 도로·파단 조각의 충돌 판정과 구조 하중 계산은 유지합니다.

접지 중인 차량의 높이와 목표 기울기는 실제 차량 종류·표시 크기에 맞춘 앞뒤 바퀴 위치에서 도로 높이를 읽어 구합니다. 앞바퀴가 경사에 올라간 뒤에도 차체 중심이 평지에 있다는 이유로 차체가 낮게 유지되는 문제를 방지합니다. 바퀴 위치에서 주행 가능한 도로를 찾지 못하면 기존 중심 접지 처리를 사용하며, 중심 아래 도로가 사라진 경우의 낙하 처리는 유지합니다.

도로 검사 패널에는 복합 이용률·축력 이용률·휨·전단 요구량과 허용량을 표시합니다. 구조 코치와 결과 진단은 도로 휨·전단 파괴를 인장·압축 파괴와 구분합니다. AI에 보내는 상태에도 같은 수치가 포함됩니다.

재료 값은 `script.js`의 기존 `MAT`에 있습니다. `weight`는 N/u, `momentCapacity`는 N·u, `shearCapacity`는 N 기준의 게임 보정값입니다. u는 게임 월드 길이 단위이며 m가 아닙니다. 기존 JSON 재료 덮어쓰기에서 지원하는 키 목록은 변경하지 않았습니다.

샌드박스의 부재 파단 OFF는 유지합니다. 이때도 하중·이용률·변위는 계산하되, 하중 한계 초과만으로 부재를 끊지 않습니다.

## 확인한 사례

- 760u 경간, 8kN 차량, 일반 도로 5개: 기존에는 축력 이용률 0%로 완주. 수정 후 중앙 정적 복합 이용률 약 227%, 주행 중 도로 파단·붕괴로 실패.
- 같은 조건의 하부 워런 트러스: 주행 중 파단 없이 완주.
- 같은 경간을 도로 20개로 나누어도 중앙 최대 모멘트가 동일하게 계산됨.
- 강화 도로가 일반 도로보다 변위와 이용률이 낮음. 중간 실제 지지점 추가 시 이용률 감소.
- 120u 단일 패널, 중앙 8kN 집중하중: `PL/4 + wL²/8 = 243600 N·u`, `P/2 + wL/2 = 4120 N`과 계산값 일치.
- 자중을 제외한 하중 증가분의 모멘트가 선형 비례하며, 반력과 외력의 합이 평형을 만족함.
- 차축 4개인 두 차량의 총하중 분담, 부재 연결 방향 반전, 차량 진입 전 하중 제외를 확인.
- 차량·도로 벽 충돌, 측면 구조재 충돌 제외, 파단 조각 길이 유지, 튜토리얼 구조 완주를 확인.

## 모델 범위

기존 2D 트러스 해석과 도로의 기울기 기반 휨 근사를 확장한 게임 모델입니다. 회전 자유도를 갖춘 정밀 보·프레임 FEM으로 교체한 것은 아닙니다. 패널 내부의 휨 강도는 검사하지만, 패널 내부의 연속 처짐 곡선은 별도로 렌더링하지 않습니다. 케이블 해석과 충돌·카메라 시스템의 전체 구조도 유지합니다.
