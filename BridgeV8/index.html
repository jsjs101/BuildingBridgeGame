      TRUSS LAB

      실생활의 트러스교·현수교·사장교·아치교가 하중을 전달하는 방식을 배우고, 직접 구조를 설계하는 2D 교량 공학 아케이드입니다. 모든 계산은 이 브라우저 안에서 실행됩니다.
      1 · 설계

      기본 도로는 없습니다. 일반 도로(최대 180) 또는 강화 도로(최대 220)로 바닥판을 직접 만든 뒤 목재·강철·케이블로 구조를 보강합니다.

      2 · 시험

      시험을 누르면 차량이 이동합니다. 부재는 인장·압축에 따라 색이 바뀌고 변형이 확대되어 표시됩니다.

      3 · 개선

      AI 구조 코치와 교량 도감에서 하중 경로, 인장·압축, 트러스교와 현수교의 차이를 비교하며 설계를 개선합니다.

      새 편의 기능 · 연결 중에는 길이·추가 비용이 실시간 표시됩니다. 부재에 마우스를 올리면 재료와 응력 정보를 볼 수 있고, G 격자 · M 스냅 · L 하중/반력 · F 전체 화면을 사용할 수 있습니다.
      ※ 교육용 게임 모델입니다. 실제 교량 설계·안전 판정에는 사용할 수 없습니다.

      교량 구조 도감

      다리는 같은 하중을 받아도 구조 형식에 따라 힘을 전달하는 길이 달라집니다. 아래 구조를 비교한 뒤 스테이지에서 직접 확인해 보세요.

      △ 트러스교

      삼각형 부재가 주로 축력(인장·압축)으로 하중을 나눕니다. 재료를 효율적으로 쓰기 좋아 철도교·도로교에서 널리 사용됩니다. 실제 예로 영국의 포스 브리지(Forth Bridge)는 거대한 캔틸레버 트러스 구조로 유명합니다.

      핵심: 삼각형 · 축력 · 하중 분산

      ⌒ 현수교

      주 케이블이 인장으로 하중을 받고, 행어가 바닥판 하중을 케이블에 전달합니다. 주탑은 큰 압축을 받으며 매우 긴 경간에 유리합니다. 골든게이트교와 아카시 해협 대교가 대표적인 현수교입니다.

      핵심: 케이블 인장 · 주탑 압축

      ╱ 사장교

      주탑에서 도로로 뻗은 케이블이 하중을 직접 지지합니다. 현수교보다 하중 경로가 짧고, 중·장경간 교량에서 자주 쓰입니다. 프랑스의 미요 대교(Millau Viaduct)가 대표적인 사장교입니다.

      핵심: 직접 케이블 지지

      ∩ 아치교

      아치가 주로 압축으로 하중을 양쪽 지점에 전달합니다. 지점에는 바깥쪽으로 미는 수평 추력이 생기므로 단단한 기초가 중요합니다. 시드니 하버 브리지는 거대한 강철 아치교의 대표 사례입니다.

      핵심: 압축 · 수평 추력

      왜 트러스는 하중을 잘 버틸까?

      삼각형은 세 변의 길이가 정해지면 모양이 쉽게 찌그러지지 않습니다. 핀 접합으로 단순화한 트러스에서는 외력이 주로 각 부재의 길이 방향으로 전달되어, 부재가 인장 또는 압축을 담당합니다. 그래서 같은 양의 재료를 단순한 보처럼 쓰는 것보다 힘의 경로를 명확하게 만들 수 있습니다.

      ① 삼각형의 기하학적 안정성
      사각형은 대각선이 없으면 평행사변형처럼 변형될 수 있지만, 삼각형은 형태를 유지하기 쉽습니다.
      ② 축력 중심의 하중 전달
      잘 배치된 트러스 부재는 굽힘보다 인장·압축 축력으로 하중을 전달해 재료를 효율적으로 사용합니다.
      ③ 여러 하중 경로
      연속된 삼각형은 차량 하중을 여러 부재와 지점으로 나누어 특정 한 곳에 힘이 몰리는 것을 줄입니다.

      구조 선택은 언제 달라질까?

      • 트러스교: 비교적 짧거나 중간 경간, 강성이 필요하고 부재 조립이 유리할 때.
      • 현수교: 매우 긴 경간에서 케이블 인장을 활용할 때. 앵커리지와 주탑이 중요합니다.
      • 사장교: 중·장경간에서 주탑과 케이블이 바닥판을 직접 지지하도록 할 때.
      • 아치교: 압축을 잘 전달할 수 있고 양쪽 지반이 수평 추력을 받아줄 수 있을 때.
      ※ 이 게임의 구조해석은 2D 핀 접합 트러스 모델을 중심으로 단순화되어 있습니다. 실제 현수교·아치교의 상세 거동과 설계는 훨씬 복잡합니다.
