# 겨울 배경과 그래픽 설정

실제 게임은 `BridgeV6/index.html`입니다. 기존 Canvas 2D 방식을 유지하며, 배경만 `environment.js`로 분리했습니다. 별도 라이브러리나 이미지 다운로드는 사용하지 않습니다.

## 사용 방법

게임 중 **도구 → UI · 그래픽 설정 → 배경 그래픽**에서 설정합니다. 메인 메뉴의 플레이 설정에서도 같은 옵션을 바꿀 수 있습니다.

- **최적화 모드**: 산맥 레이어, 캐시 해상도, 장식, 눈과 날씨 효과를 줄입니다.
- **단조로운 배경**: 간결한 산맥·소수의 나무를 표시하며 눈·비·바람 장식 효과를 생략합니다. 실제 하중과 날씨 조건은 유지됩니다.
- 두 옵션은 독립적이며 변경 즉시 적용됩니다. `trusslab-ui-graphics-optimized`, `trusslab-ui-graphics-simple`에 저장합니다.
- `project-settings.json`의 같은 이름을 가진 `uiDefaults` 값으로 첫 실행 기본값을 지정할 수 있습니다. 저장된 사용자 선택이 우선합니다.
- 기존 ‘동작 줄이기’ 설정은 자동 환경 애니메이션과 패럴랙스 이동을 줄입니다.

## 구현과 자원 제한

| 설정 | 산맥 레이어 | 눈 입자 상한 | 래스터 캐시 수 (하늘 포함) | 배경만을 위한 유휴 갱신 |
|---|---:|---:|---:|---:|
| 고품질 | 4 | 44 | 5 | 최대 30회/초 |
| 최적화 | 3 | 12 | 4 | 최대 20회/초 |
| 단조로운 배경 | 2 | 0 | 3 | 없음 |
| 두 옵션 모두 | 1 | 0 | 2 | 없음 |

- 산맥의 불규칙한 능선, 원근 색상, 안개와 달빛을 오프스크린 Canvas에 한 번 그려 재사용합니다. 매 프레임 산맥·조명 도형을 다시 생성하지 않습니다.
- 세 종류의 소나무와 바위는 `Path2D`를 공유합니다. 절벽 면도 미리 계산하며, 눈은 한 경로로 묶어 그립니다.
- 나무·바위·눈더미·절벽 면은 화면 밖에서 생략합니다. 줌아웃 시 일부 나무를 생략합니다.
- 캐시는 현재 장면 한 벌만 유지합니다. 스테이지·절벽 끝점·옵션이 바뀌면 이전 Canvas 크기를 해제하고 교체합니다. 창 크기 변경이나 일반 프레임마다 재생성하지 않습니다.
- 기존 `devMonitorFrame`에 유휴 갱신만 연결했습니다. 별도의 반복 RAF·타이머는 추가하지 않았습니다. 시뮬레이션 중에는 기존 시험 루프가 그리기를 담당합니다. 메뉴·숨겨진 탭·동작 줄이기 상태에서는 유휴 갱신을 생략합니다.
- 카메라 입력과 좌표 변환은 그대로이며, 산맥에만 별도의 시각적 패럴랙스를 적용합니다. 장식 절벽은 충돌 도형으로 사용하지 않습니다.

## 확인한 항목

- 옵션 네 조합, 키보드 전환, 두 설정 화면의 동기화, 새로고침 후 저장 유지.
- 반복 전환 96회 후 캐시 개수 상한 유지와 가비지 수집 후 힙 상태 확인.
- 48개 계약 × 네 옵션 조합 × 카메라 두 극단 = 384개 배경 렌더링, 화면 모서리의 빈 픽셀 없음.
- 맑음·흐림·비·폭풍·바람, 동작 줄이기, 튜토리얼, 샌드박스 워런 구조의 시험 시작·중지.
- 주행 시험 중 네 그래픽 조합으로 전환해도 관절·부재·스테이지·카메라 값이 유지되고 주행 진행률이 계속 증가함을 확인했습니다.
- 1100×768 / DPR 2에서 설정 스크롤과 버튼 접근 확인.
- 기존 물리·충돌·차량·카메라 소스 구간을 비교했고, 그래픽 전환 전후 관절·부재·스테이지·카메라·물리 설정 값이 일치함을 확인했습니다.

## 측정 범위

자동 브라우저(Headless Microsoft Edge), 1560×960 / DPR 1에서 각 모드 90프레임을 측정했습니다. 전체 `draw()` 호출의 중앙값은 기존 약 0.7ms, 새 고품질 약 0.5ms, 최적화 약 0.6ms였습니다. 브라우저·샘플에 따라 달라질 수 있는 짧은 JavaScript 제출 시간 측정이며 GPU 작업 완료 시간이나 실기기 FPS 보장은 아닙니다.

고품질의 정적 배경 캐시는 약 528만 픽셀, 최적화는 약 195만 픽셀로 약 63% 적습니다. 두 옵션을 모두 켜면 약 117만 픽셀입니다. RGBA 원시 데이터로 환산하면 각각 약 20.1 / 7.4 / 4.5 MiB이며 브라우저의 실제 GPU 메모리 수치는 별도입니다. 저사양 실기기의 CPU/GPU 사용률과 장시간 FPS는 직접 측정하지 않았습니다.
